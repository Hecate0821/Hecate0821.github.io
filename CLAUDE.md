# Personal Site Notes

- Keep the homepage profile style separate from the blog reading style. Blog pages should use one readable article font across title, headings, metadata, captions, and body; reserve monospace only for code.
- Content links should be obvious. Use the accent color with an underline/border for article links and blog titles. Keep navigation links quieter.
- Blog cards on the homepage should use the left column for publish date, not category.
- Avoid repeating the blog title and description inside the thumbnail card when the row already has a title and intro.
- Light mode should stay neutral-warm, not beige-heavy and not pure white. Current middle background: `#f1eadc`.
- Do not commit or push unless explicitly asked.
